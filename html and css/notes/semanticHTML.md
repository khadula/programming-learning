```
<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>

each of these are virtually identical to divs but they give more information when reading the files

<section> defines a seciton in a document
- eg; chapters, introduction, news items, etc

<article> specifies independent, self-contained content
- eg; forum posts, blog posts, user comments

<nav> is typically a set of navigation links
- eg; a navigation bar

<footer> is a footer for a document or section
- eg; authorship info, copyright info, sitemap, back to top links, etc

<header> is a container for introductory content or navigational links
- typically has one or more heading elements (h1, h2, etc)
- logo/icon

<aside> defines some content aside from the content it is placed in (like a sidebar)
- should be indirectly related to the surrounding content
```
